# 宇宙シミュレーションゲーム企画（Android / Windows）

## 1. コンセプト
- **タイトル案**: Solar Origin
- **ジャンル**: 宇宙シミュレーション / サンドボックス / 学習要素付き
- **対象プラットフォーム**: Android / Windows
- **原点座標**: 太陽（Solar-centric）
- **メイン領域**: 太陽系（高精度）
- **拡張領域**: 銀河内の恒星カタログ（可変精度）

プレイヤーは太陽を基準点として、時間の進行速度・重力スケール・初期条件などを調整しながら、太陽系を中心に宇宙の挙動をシミュレーションします。

---

## 2. 重要な前提（「リアルに存在するすべての星」への対応）
現実的には「宇宙に存在するすべての星」を完全収録することは不可能です。そこで以下の段階戦略を採用します。

1. **太陽系（必須・高精度）**
   - 太陽、8惑星、準惑星、主要衛星、小天体群を高精度に再現。
2. **近傍恒星（中精度）**
   - Gaia / Hipparcos 等の観測カタログを利用し、位置・固有運動・光度を反映。
3. **遠方恒星（低精度・統計生成）**
   - 観測データのある星を優先し、欠損領域は天の川銀河モデルで統計補完。

> これにより、**科学的妥当性**と**実行性能**を両立できます。

---

## 3. ゲームのコア機能

### 3.1 太陽系シミュレーション（主軸）
- N体計算による重力シミュレーション（近似レベルを選択可能）
- 公転・自転・離心率・軌道傾斜を反映
- ラグランジュ点表示
- 日食・月食・会合イベントの予測

### 3.2 時間制御
- 1秒〜10,000年/秒の時間加速
- 一時停止、巻き戻し（スナップショット方式）
- 特定日時（例: 2050/01/01）へのジャンプ

### 3.3 パラメータ編集（サンドボックス）
- 万有引力定数 G のスケール変更
- 天体質量・初速・位置の編集
- 小惑星衝突シナリオの作成
- 恒星進化パラメータ（簡易モデル）

### 3.4 可視化
- 2D軌道図 / 3D宇宙空間表示の切替
- 距離スケール切替（太陽系内 / 恒星間）
- 温度・重力ポテンシャル・軌道安定性ヒートマップ
- HUD: 距離、速度、質量、軌道周期

## 4. 技術構成（Android / Windows両対応）

### 推奨エンジン
- **Unity (URP)**
  - Android / Windowsの同時展開が容易
  - モバイル最適化ノウハウが豊富
  - 豊富なアセットと開発者人口

### システム分割
1. **Simulation Core（C#）**
   - 物理計算、時間制御、データ同期待機列
2. **Data Layer**
   - 太陽系初期値、恒星カタログ、LOD管理
3. **Rendering Layer**
   - 近距離は高精細メッシュ、遠距離はBillboard/Point描画
4. **Scenario/Save Layer**
   - JSONセーブ、スナップショット差分保存

### パフォーマンス戦略
- LOD（距離別で計算頻度と描画精度を切替）
- Burst + Jobs（Unity）で並列化
- 固定ステップと可変ステップのハイブリッド
- モバイル向けに最大描画星数を動的調整

## 5. データソース案
- **JPL Horizons / SPICE**: 太陽系天体の高精度位置
- **Gaia DR3**: 恒星の位置・距離・固有運動

- **SIMBAD（参照）**: 天体メタデータ確認

※ ライセンスと再配布条件は要確認。

## 7. 実装時の注意点
- すべての天体を同じ精度で計算すると破綻するため、**領域ごとの精度階層設計**が必須。
- 長時間シミュレーションでは数値誤差が蓄積するため、定期的な基準座標再正規化を実施。
- モバイル熱問題に備え、30/60fpsの自動切替を実装。
